# SmartBudgetManager
A project for managing Budget.
A small company has created an Excel workbook called SmartBudget Manager (SmartBudget_Manager.xlsx). The
workbook helps users in:
 Record monthly income and expenses
 Categorize expenses
 Calculate the monthly balance automatically
 Display a chart of expenses by category
 Receive a warning when the budget limit is exceeded
Students must act as technical writers. Their task is not to create a complex Excel system from scratch; it is to document a
simple, real Excel workbook as if it were a product delivered to end users.
The workbook contains three worksheets:
Worksheet Purpose
Dashboard Shows monthly balance, total income, total expenses, and charts
Transactions Allows the user to enter income and expenses
Categories Contains predefined categories such as Food, Transport, Rent, Health, and Education
The workbook include formulas such as:
 SUM() for totals
 SUMIF() or SUMIFS() for totals by category
 A basic pie chart or column chart
 Conditional formatting to show overspending
Students may use Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible version.

Example procedure
Add an expense
Purpose: Use this procedure to record a purchase or payment.
Before you begin: Open the Transactions worksheet.
1. Select the first empty row in the transaction table.
2. Enter the transaction date in the Date column.
3. Type a description in the Description column.
Example: Electricity bill.
4. Select a category from the Category list.
5. Enter the amount in the Expense column.
6. Press Enter.
7. Open the Dashboard worksheet to verify that the total expense amount has updated.
Expected result: The expense appears in the transaction table and the dashboard recalculates the monthly
balance.
